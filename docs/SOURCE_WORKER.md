# عامل البحث الدوري للمراجعة

العامل الجديد مستقل عن العامل القديم، ولا يحذف أي ملف أو يعدل أسعار الكتالوج أو يشتري منتجات. يستخدم نفس محول المصادر وقواعد مطابقة المنتج وشراء القطعة ومعادلة التسعير المستخدمة في البحث الفوري.

التشغيل بعد توفير مصادر معتمدة:

```sh
node services/scraper/source-worker.mjs --once
# تشغيل مستمر؛ الدورة التالية تبدأ بعد انتهاء الحالية
node services/scraper/source-worker.mjs
```

الإعدادات في بيئة الخادم، وليست في المتصفح:

- `APPROVED_SOURCE_FEEDS`: قائمة المصادر بنفس صيغة إعداد البحث الفوري: `name`, `endpoint` HTTPS, `supplierId`, `directFulfillmentAgreed`, `allowsSingleUnits`، و`tokenEnv` اختياري لاسم متغير سر المصدر.
- `SOURCE_WATCH_QUERIES`: قائمة JSON لعبارات المنتجات، من 1 إلى 100 عبارة، طول العبارة 2 إلى 120 حرفًا.
- `SOURCE_INTERVAL_SECONDS`: الافتراضي 900 ثانية، الحد الأدنى 60 ثانية.
- `SOURCE_REVIEW_PATH`: الافتراضي `var/source-review.json`. يحتوي تكلفة المورد ومعرفه؛ يجب إبقاؤه خاصًا بالخادم خارج مجلد الموقع العام. الملف مستبعد من Git.

تُكتب اللقطة باستخدام استبدال ملف بعد اكتمال الكتابة وصلاحيات خاصة. عند تعطل مصدر، تُحفظ اللقطة السابقة كدليل تاريخي غير صالح للتسعير الحالي، ولا تُعرض نتائج مخزنة على أنها بحث ناجح. عند فشل الدورة بالكامل يبقى الملف السابق. شغّل نسخة واحدة فقط من العامل لكل ملف نتائج، مع مشرف خدمة يعيد تشغيله عند توقف الخادم.

هذا يجهز التشغيل الدوري، لكنه لا يوفر مصادر فعلية تلقائيًا ولا يربط النتائج بالكتالوج أو يفعّل الشراء. لا توجد مصادر فعلية مهيأة حتى الآن.
