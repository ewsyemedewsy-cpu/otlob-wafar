# تشغيل نسخة تجارب على Cloudflare

الملف `wrangler.testing.json` ومدخل `services/api/src/cloudflare-worker.js` يشغّلان نفس تطبيق Express داخل Workers. تشغيل Node الأصلي محفوظ. يتوقف مؤقت تنظيف حدود الطلبات في وضع Workers ويُنظف عند استقبال الطلبات بدلًا منه.

## ما تم التحقق منه

بناء Wrangler التجريبي نجح دون نشر. اختبار `npm run test:worker` يستخدم محاكي Workers الحقيقي ومفاتيح وهمية فقط، ويتحقق من فحص الصحة وCORS وحماية الإدارة ورفض الطلب غير الصحيح وتوقيع الدفع غير الصحيح وعدم إظهار نتائج مصادر غير متصلة والتسعير مع الرسوم. نجحت أيضًا اختبارات Node الحالية وعددها 39 محليًا.

اختبار المحاكي لا يثبت اتصال Supabase الحقيقي أو أداء خطة Cloudflare المجانية، ولا يغني عن طلب كامل على الموقع المنشور. لا توجد استضافة منشورة بهذا الملف بعد.

## قبل النشر

1. استخدم قاعدة التجارب فقط. ضع `SUPABASE_URL` و`PUBLIC_ORIGIN` في إعدادات Worker، ومفتاح قاعدة التجارب `SUPABASE_SECRET_KEY` ومفتاح الإدارة `ADMIN_API_KEY` كأسرار. لا تسجلها في Git أو المحادثة أو واجهة العميل.
2. احتفظ بالدفع الإلكتروني ومصادر البحث والإرسال والشحن الحي متوقفة أثناء التجربة. لا تشغل عمال إشعارات الطلبات الاختبارية.
3. نفّذ بناء الواجهة بعنوان الخادم الفعلي في `VITE_API_URL`، واسمح بعنوان الواجهة فقط في `PUBLIC_ORIGIN`.
4. اختبر طلب دفع عند الاستلام من المتصفح حتى قاعدة التجارب، مع الإلغاء والمخزون وسجل الإدارة.
5. قبل قبول طلبات حقيقية، افحص هوية عنوان العميل وراء Cloudflare، وحدود الطلبات المشتركة بين النسخ، وحدود CPU اليومية وحجم البناء على الخطة الفعلية. حدود الطلبات الحالية في ذاكرة النسخة ولا تكفي بمفردها لمكافحة إساءة الاستخدام على عدة نسخ.

للبناء دون نشر: `npx wrangler deploy --config wrangler.testing.json --dry-run`. نشر نسخة التجارب يتطلب وصولًا آمنًا لحساب Cloudflare وإعداد الأسرار أولًا. لم تتم إضافة حساب أو اشتراك أو بيانات بطاقة بهذه التغييرات.

المصدر: https://developers.cloudflare.com/workers/tutorials/deploy-an-express-app/

## عنوان العميل وحدود الطلبات

المحوّل يستبدل سلسلة `X-Forwarded-For` التي يرسلها المتصل بعنوان `CF-Connecting-IP` الصحيح الذي يوفره مدخل Workers، ويحذف ترويسات التحويل البديلة. اختبار المحاكي يثبت أن تغيير سلسلة التحويل لا يتجاوز حد 12 طلبًا، وأن زائرًا آخر لا يُحجب بسبب ذلك الزائر. إذا غاب عنوان Cloudflare أو كان غير صالح، لا يُعتمد عنوان يختاره المتصل.

هذا مخصص للدخول عبر Cloudflare Workers نفسه؛ ليس قاعدة ثقة تصلح لخادم Node عام أو لأي وسيط غير معتمد. ما زالت الحماية المشتركة بين النسخ وفحص مسار الدخول الفعلي مطلوبين قبل الإطلاق التجاري.
